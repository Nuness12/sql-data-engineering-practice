# sql-data-engineering-practice
Repositório destinado à prática e ao aprofundamento de SQL, com foco na minha transição profissional para Engenharia de Dados.

Objetivo

Desenvolver e aprimorar competências em consultas SQL, análise, transformação, validação e qualidade de dados, por meio de exercícios técnicos e desafios práticos.

Tecnologias

SQL Server / T-SQL

PostgreSQL

SQL Fiddle

DataLemur

Conteúdos praticados

JOINs e subconsultas

Common Table Expressions (CTEs)

Funções de janela: ROW_NUMBER, DENSE_RANK, LAG

Agregações: COUNT, SUM, AVG

Identificação de registros duplicados

Validação e tratamento de inconsistências

Análise de indicadores e volumes

Organização

datalemur/ — Minhas soluções de exercícios de SQL voltados a entrevistas técnicas.

laboratorio_carteiras/ — Exercícios utilizando dados fictícios de carteiras de cobrança, com foco em qualidade e validação de dados.

Contexto profissional

Sou formado em Banco de Dados pela Impacta Tecnologia e possuo experiência profissional em análise, tratamento e validação de informações, utilizando SQL Server e Excel.

Este repositório documenta minha evolução técnica e meus estudos voltados à Engenharia de Dados.
